# 扩展钢琴音源与自定义键位试用版

安装文件：pianofx-0.1.0-extended-piano.jar。Minecraft 1.21.1 / Fabric。替换现有 PianoFX，只保留一个版本；无需另外安装 ExtendedNoteBlock。

## 音色

本版从用户提供的 ExtendedNoteBlock 1.9.1 移植其钢琴音源与按音符时值延音、释放淡出的设计，附上上游授权。并非装入整个 ExtendedNoteBlock，不添加它的红石、网络或额外方块系统。

它内置的 GeneralUser GS 音色包每个旋律乐器只有 C4 一个采样，本版直接保留其 Grand（0.60.ogg）与 Bright（1.60.ogg）原文件，没有再次从旋律录音里提取音色。

默认“扩展钢琴 Bright”：MIDI 48～72 使用该 C4 音源按正确频率比移调，控制在 Minecraft 0.5～2 倍安全范围；范围外自动改用之前约 7MB 版中逐音高生成的 Bright Piano 多采样，避免大跨度变调。还可切换为“扩展钢琴 Grand”或全范围“原版多采样 Bright”。旧版 128 个采样保持字节一致，1MB 录音提取版未用于本包。

这仍然是音源集成试用版；C4 单采样移调与多采样的音色可能存在差异，不能承诺等同于原始插件或完全消除所有听感问题。

## 自定义键位

打开钢琴界面，点击右上角“自定义键位 [F6]”或按 F6。

- 演奏状态：鼠标或键盘按住琴键发声，松开后短暂淡出；左右方向键切换八度。
- 点击“编辑布局”：左键拖动屏幕琴键位置，右键选择琴键后按新的键盘按键重绑。
- 同一个键被重新绑定时，两颗琴键交换绑定，避免重复占用。
- “完成布局”返回演奏。可单独重置位置或重置绑定。
- 位置以比例坐标保存到当前游戏实例的 config/pianofx-controls.json，重开和改变窗口尺寸后保留；该配置不会写入 MOD JAR。
- Esc、Tab、F6 和左右方向键留给界面控制，不参与重绑。

自定义界面的绘制顺序已修复：原版菜单背景模糊先执行，文字与琴键后绘制，避免整个键盘被模糊。

## 物品图标

旧图标引用没有几何面的方块模型，所以背包一直空白。本版新增独立三维物品模型，包含琴身、琴盖、琴键和琴腿；调整朝向，使背包内能看到键盘，并缩小至物品格尺寸。原世界内钢琴模型保持不变。

## 验证与保留

隐藏 Minecraft 客户端完成 384 个音色/音高选择校验、130 个 OGG 实际 STB Vorbis 解码、延音与释放淡出、F6 入口、拖拽、重绑、冲突交换和 JSON 保存验证。物品模型烘焙出 120 个可渲染面，并拍摄背包和放大物品渲染实机画面。

三螺旋、彩虹轨道、曲线五线谱、离地两格、音符替换和结束破碎消散逻辑以及世界内钢琴渲染器，均与已验证的修复版字节一致。
