# 用户录音音色版

安装 pianofx-0.1.0-user-piano.jar，替换当前安装的 PianoFX JAR，只保留一份。Minecraft 1.21.1 / Fabric。

本次只换声音：将用户提供的 bright-piano-melody-juice-wrld-type-metro_167bpm_B_minor.wav 提取为可按 MIDI 键位播放的采样。原有三螺旋、离地两格的曲线五线谱、音符替换、结束破碎消散和钢琴发光逻辑均与已验证的上一版字节一致。

WAV 与 OGG 均为同一段约 22.994 秒的旋律录音，WAV 作为提取源。由于包含和弦与残响，不是独立单音音源，本版通过谐波过滤提取四个主音区域，再移调映射 128 个 MIDI 键位。这是录音音色的近似还原，不能等同于原始钢琴插件或完整多力度采样库；没有把整段旋律作为每个键的声音，也不混入上一版 GM 音色。

提取区域：B3（0～0.49 秒）、E4（0.49～1.04 秒）、C#5（1.74～2.29 秒）、D5（0～0.49 秒）。保留区域的原始相位与衰减，移调时做抗混叠与短淡入淡出；移调会改变采样时长。

试听文件 verification/user-piano/user-piano-preview.wav 与 .ogg 使用最终 JAR 中同一批采样合成。来源音频保存在 tools/audio/user-reference/，没有将原始整段录音塞进 MOD。

检查：128 个 OGG 均已解码验证非静音、无削波、有限值与端点渐变。包对比在 verification/user-piano/jar-diff.json，音频检查在 audio-checks.json。游戏内加载记录在 runtime-audit.log。

构建：tools/build-user-piano.ps1。重新提取采样：tools/audio/build-user-piano.py。回退包：backup/before-user-piano/pianofx-0.1.0-score-staff-fixed.jar。
