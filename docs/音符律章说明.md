# 音符律章修复版（2026-10-21）

安装文件：pianofx-0.1.0-score-staff-fixed.jar。替换旧 PianoFX，同一实例只保留一个 PianoFX JAR。Minecraft 1.21.1 / Fabric。

## 本次修复

- 歌曲自然播放完毕或点击停止后，所有阶段的音符分批缩小、淡出、飘散，并释放彩色碎光；五线谱分段瓦解，彩虹轨道停止补画并逐渐消散。视觉退场约 10～12 秒，16 秒内完成剩余粒子与句柄清理。不会提前在歌曲最后九秒触发退场。
- 暂停不触发退场。新曲和重新手动演奏会复位结束状态，不继承上一次已经消失的谱面。
- 钢琴模型使用全亮光照，并给琴身底边和琴盖增加细的自发光轮廓。黑色主体保留。无光影时能看到明亮的边缘与琴键，泛光强弱取决于光影包；这不是改变周围方块亮度的动态光源。
- 原版音效混合改为 GM Bright Piano（program 1，TimGM6mb 中的 Piano 2）采样。0～108 音高从预设渲染，109～127 由最高音采样离线升调扩展；播放不再折回八度。力度控制音量。每个采样包含约 1.8 秒按键与自然释放尾音，未新增长音持续踏板模拟。
- 五线谱中线静态基准为支撑地面上方两格；五条线间距 0.5 格，曲线波浪保留并收敛幅度，避免降高后穿入地面。实机使用与 UI 相同的钢琴锚点，记录高度为 2.0。

## 保留范围

原始 Spiral、Ribbon、SparkParticle 和底层渲染表、Mixin 均保持字节一致，三螺旋形状、圈数、高度、半径和彩色轨道绘制方式没有改写。

相对原始 JAR，替换 Flyer、FxManager、NoteSound、ScorePlayer、PianoRenderer 五个类；新增独立五线谱类、音色采样和音色授权来源。测试夹具没有进入正式安装包。原始 JAR 未覆盖，上一版保存在 backup/before-ending-fix/。

## 验证

- 数值测试：1,185 颗音符完整运动流程通过，最多 69 个谱位、1,116 次替换，螺旋坐标与原版一致。
- 退场测试：70 颗错开出生时间的音符覆盖上升、转移和入谱状态，最终音符、预约位和谱面透明度全部归零；两种原始播放锚点均校验中线离地两格。
- 隐藏 Minecraft 客户端：70 秒曲目 234 个音符，暂停/继续，自然播完，重播两秒短曲均通过；退场后存活特效粒子为零。128 个 Bright Piano 声音事件全部注册。
- 截图和动图来自隐藏客户端真实帧缓冲，未加载参考图的光影包。测试客户端保持静音；采样另行完成非静音 OGG 编解码检查。
